# Privacy Policy – rclone (Suparig)

*Effective November 12, 2026*

"rclone" is a Google OAuth app registered by Suparig (suparig.com) for personal use. It is a configuration of [rclone](https://rclone.org), an open-source command-line tool, used by its owner to copy and manage files in the owner's own Google Drive, such as Google Takeout archives.

## Data accessed

When authorized, the app can access files in the Google Drive account that granted access, and read, download, upload, and organize them as directed by the account owner.

## How data is used

Data is used only to transfer files between the owner's Google Drive and the owner's own computer or storage. It is not used for advertising, analytics, or profiling.

## Sharing

No data is sold, rented, or shared with third parties. The developer runs no server that receives your data. Transfers happen directly between Google and the computer running rclone.

## Storage and revocation

Access tokens are stored only in the rclone configuration file on the owner's computer. Access can be revoked at any time at https://myaccount.google.com/permissions.

## Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
